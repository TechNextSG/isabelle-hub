Claude skills and tools

What runs each step. All tools live on the TechNext work PC (ClaudeWork); the skill is in Claude Code.

Claude skill

isabelle-new-event

The full new-event workflow: pages on all 3 sites, then the event kit and schedule, then the coverage gate. Triggers on any new event request.

Tool

event_kit.py

One command per event: thumbnail, poster, 4 social posts, captions, Drive delivery, 5 schedule rows, push + tracker refresh.

Tool

new_event.py · social.py

The site-card / poster renderer and the 4:5 social post design (HummingBeing card style, cut-out trainers, partner logos).

Gate + hook

event_coverage.py

Lists upcoming events on hummingbeing.com and fails if any has no materials or schedule. A Claude Code hook runs it after every git push.

Tool

Schedule plan (fix.py · check.py · build.py)

Owner rules: next event daily, others weekends, max 2 a day (AM/PM). New events register in events_registry.json.

Tool

swap_dates.py · patch.py

Change requests: dry-run sweeps across the 3 repos; in-place artwork date patches with a font-match self-check.

Tool

sync_cert.py (Buffer)

Buffer sync with dry run, per-post backups and a re-read check. Runs only after the owner says GO.

Tool

TRE _src/build.py

Builds every TRE page from the data files: clean URLs, search data, sitemap, image variants, blog drafts.
