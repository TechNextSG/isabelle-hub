# Isabelle hub

One page listing every website and HTML page TechNext built for Isabelle Claus Teixeira (noindex, unlisted).

- `python tools/fetch_pages.py` – refresh the page lists from the three sitemaps
- `python tools/thumbs.py [slug]` – refresh card pictures
- `python tools/build.py` – write index.html (cards live in tools/hub_data.py)
